ZR.Lab — static export
======================
index.html   Fully rendered page markup
styles.css   Compiled Tailwind v4 stylesheet (all design tokens included)
script.js    Smooth-scroll for the nav anchors
assets/      Case-study images (jpg) + compiled React bundles (index-*.js, routes-*.js)
favicon.ico

Fonts load from Google Fonts (link tags in index.html), so keep an internet connection.
Note: interactive React features (case-study modals, mobile swipe sliders, scroll offer
popup) come from the React app; the static HTML shows their default rendered state.
